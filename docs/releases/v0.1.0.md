# RedLake AI v0.1.0 — Catalog & Batch Ingestion Foundation

## Summary

The first RedLake AI release creates the durable boundary between untrusted source data and a future lakehouse. It receives CSV/JSON files, creates profile and quality evidence, retains raw/quarantine bytes, and records the outcome in a versioned catalog.

## Included

- FastAPI control-plane API and OpenAPI documentation.
- Dataset catalog and active versioned data contracts.
- CSV/JSON parser with scalar type profiling.
- Error-level quality checks and quarantine semantics.
- Idempotency key / SHA-256 content protection.
- Filesystem and S3-compatible storage adapters.
- PostgreSQL-oriented Alembic migration, MinIO/PostgreSQL/Prometheus Compose stack.
- JSON logs, request IDs, health/readiness endpoints, Prometheus metrics.
- Automated API/domain tests and GitHub Actions CI.

## Explicitly not included

No API connector, Kafka, Spark, Iceberg, dbt, Airflow, SQL serving engine, MLflow workflow, LangGraph agent, Kubernetes deployment, authentication, or multi-tenancy is claimed in this release.
